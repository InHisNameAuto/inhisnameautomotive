## How to Deploy

### Option 1: GitHub Pages
1. Go to your repository settings
2. Scroll to "GitHub Pages"
3. Select "main" branch as source
4. Your site will be published at `https://InHisNameAuto.github.io/inhisnameautomotive`

### Option 2: Custom Domain
1. Update your domain's DNS records to point to GitHub Pages
2. Add your domain in repository settings
3. Your site will be available at your custom domain (e.g., InHisNameAutomotive.com)

## Customization

### Adding Your Logo
Add your logo image as `logo.png` in the root directory. The website references it in the About section.

### Updating Contact Information
Edit the contact details in `index.html` to update phone, email, or address.

### Changing Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --navy: #1a2f4a;
    --gold: #d4a574;
    /* ... other colors */
}
```
